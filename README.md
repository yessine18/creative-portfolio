# 🎬 Yessine Fakhfakh — Audio Visual Artist Portfolio

A premium, high-performance portfolio website showcasing audio-visual artistry, motion graphics, video editing, and national event media campaigns created by **Yessine Fakhfakh**.

## ✨ Features

- 🦸 **Hero Showcase**: High-impact side-by-side cover with stylized layout and custom typography tokens (**Mollies**, **Bricolage Grotesque**, **Luxerie Display**).
- ⚡ **Creative Software Stack**: Interactive 3D glassmorphic dashboard detailing expertise across **Adobe Illustrator**, **Adobe Photoshop**, **Adobe Premiere Pro**, **Adobe After Effects**, and **DaVinci Resolve**.
- 🗺️ **Creative Journey**: Continuous marquee timeline highlighting leadership roles, media management, and award-winning milestones across national engineering congresses.
- 🖼️ **Social Media Posters**: Dual-row continuous infinite marquee displaying 100+ promotional poster designs with interactive **Lightbox Modal Preview**.
- 🎨 **Social Media Events Branding**: Full campaign showcase for national events:
  - Tunisian Students & Young Professionals Congress 13th Edition (**TSYP 13**)
  - IEEE ENIS Student Branch
  - Hello World 4.0 CP Competition
  - Tunisian Engineering Congress Week 2.0 (**TecWeek 2.0**)
  - Tunisian Engineering Congress Week 1.0 (**TecWeek 1.0**)
- 🏷️ **Branding Logos Showcase**: Scaled and equalized high-resolution logo grid.
- 📩 **Connect & Brief Submission**: Interactive project brief contact form with smooth visual status indicators.

- **Core**: HTML5, Vanilla CSS3 (Custom Design Tokens, Glassmorphism, Ambient Spotlights), Modern ES6+ JavaScript
- **Bundler**: [Vite](https://vitejs.dev/)

## 🚀 Quick Start & Local Setup

### Prerequisites

Make sure you have **Node.js** (v16+) installed.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yessine18/freelancing-portfolio.git
   cd freelancing-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
   The production bundle will be generated inside the `dist/` directory.

---

## 🌐 Free Deployment (Vercel)

1. Sign in to [Vercel](https://vercel.com) using your GitHub account.
2. Import `yessine18/freelancing-portfolio`.
3. Vercel will automatically detect **Vite** settings (`npm run build`, output: `dist`).
4. Click **Deploy**.
